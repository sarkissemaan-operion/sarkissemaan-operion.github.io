PROGRAM OUTPUT DRIVER

Preview is always shown in this browser only, and is never sent to hardware. For Program: on a Blackmagic/AJA "monitor" device (UltraStudio Monitor 3G, Mini Monitor 4K, DeckLink Mini Monitor 4K) set to extend the desktop, the ⛶ OUTPUT button above the Program monitor sends real video to it directly from this browser tab — no native app required. Capture-only/SDI-only cards with no display surface still can't be addressed from a web page; those need a native app or Electron shell using the vendor's SDK.

UNIVERSAL INGEST ENGINE

Powered by FFmpeg.wasm (single-threaded core). It tries a fast remux first (repackaging without re-encoding — seconds, no quality loss), and only falls back to a full transcode to H.264/AAC when the source codec itself isn't browser-playable. Files stay local to this tab; nothing is uploaded.

LIVE CONFIDENCE DELAY

Auto estimates a safe delay from this device's own rendering performance. Manual lets you fix an exact delay. This is a monitoring buffer by default — it only reaches air when you deliberately choose the DELAYED variant on Preview or in a rundown live item, at which point its audio is delayed to match, not just the picture.
