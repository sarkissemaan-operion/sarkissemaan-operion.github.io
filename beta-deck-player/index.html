First use downloads the engine once (~30MB); a remux is usually seconds, a full transcode of a long clip can take minutes on modest hardware.  ·  Blackmagic / AJA output selections in Settings configure an output profile only — real SDI/HDMI hardware output still needs this deck embedded in a native app or Electron shell with the vendor driver installed.

UNIVERSAL INGEST ENGINE

Powered by FFmpeg.wasm (single-threaded core). It tries a fast remux first (repackaging without re-encoding — seconds, no quality loss), and only falls back to a full transcode to H.264/AAC when the source codec itself isn't browser-playable. Files stay local to this tab; nothing is uploaded.

DELAY MONITOR

Auto estimates a safe delay from this device's own rendering performance (a few seconds of frame-timing samples). Manual lets you fix an exact delay for cueing against a downstream broadcast or caption delay.
